# 👩‍👧 宝妈指数 (Mom Index)

> 当小白开始讨论投资，就是该警惕的时候。  
> — Joseph Kennedy, 1929

追踪中文散户社区的 "小白" 讨论热度。指数越高，散户情绪越极端，市场越危险——一个基于擦鞋童理论的行为金融学反向指标。

---

## 快速部署（Fork 即用）

本项目无需 API Key、无需数据库、无需服务器。Fork 后两步上线：

1. **Settings → Pages**：Source 选 **GitHub Actions**
2. **Actions 页面**：点击 "I understand my workflows…" 启用工作流

然后到 Actions → Daily Data Collection → Run workflow 手动触发一次，之后每个交易日下午 4 点自动运行。

## 指数公式

```
宝妈指数 = 小白占比×0.40 + 小白强度×0.25 + 情绪极端度×0.20 + 信号纯度×0.15
宝妈买入 = 买入小白占比×50 + 小白热度×30 + 买入强度×20
宝妈卖出 = 卖出小白占比×50 + 小白热度×30 + 卖出强度×20
```

## 分析方法

### 小白判定（40+ 信号关键词）

每条帖子匹配多维度信号，带可读推理：

> 帖子「亏了 20% 了要不要割肉啊」  
> 命中: 决策依赖(+7) + 情绪恐慌(+5)  
> 意图: 🔴 卖出（命中"割肉""亏了"）  
> 得分: 58 → 判定「纯小白」

| 信号维度 | 权重 | 命中示例 |
|----------|------|----------|
| 身份自述 | +8 | "小白"、"宝妈"、"新手" |
| 决策依赖 | +7 | "该不该"、"要不要"、"还能买吗" |
| 知识求助 | +6 | "怎么买"、"在哪看"、"请教" |
| 跟风行为 | +6 | "听博主说"、"朋友推荐" |
| 情绪恐慌 | +5 | "亏麻了"、"好慌"、"心态崩了" |
| 过度乐观 | +4 | "梭哈"、"满仓干"、"稳赚" |
| 专业术语 | −5 | PE / PB / 估值 / 溢价率（扣分项） |

### 意图判定

60+ 关键词区分买入 / 卖出意图：

- 🟢 买入：上车、冲、加仓、买了、还能买吗、想买、心动...
- 🔴 卖出：割肉、止损、清仓、亏了、要不要走、跌麻了...

## 项目结构

```
mom-index/
├── pipeline.py                 # 主流程：采集 → 分析 → 指数 → 存储
├── collectors/
│   ├── guba_collector.py       # 东方财富股吧采集（8 板块，反检测）
│   ├── anti_detection.py       # UA 轮换 + 隐身 + 人类行为延迟
│   └── xhs_collector.py        # 小红书备选（当前未启用）
├── analyzer/
│   ├── llm_analyzer.py         # 多维度关键词分类引擎
│   └── index_calculator.py     # 指数计算 + 历史曲线
├── frontend/
│   ├── dashboard.html          # 看板页面（Chart.js 暗色主题）
│   └── data/                   # 前端数据（pipeline 自动同步）
├── data/
│   ├── dashboard_data.json     # 前端数据源
│   └── history.json            # 完整历史记录
├── .github/workflows/
│   ├── collect.yml             # 定时采集（交易日 16:00）
│   └── deploy.yml              # GitHub Pages 部署
└── requirements.txt            # requests
```

## 本地运行

```bash
# 安装依赖
pip install -r requirements.txt

# 运行完整流程
python pipeline.py

# 启动前端看板
cd frontend && python -m http.server 8765
# 浏览器打开 http://localhost:8765/dashboard.html
```

本地运行时采集器会走本地代理 `127.0.0.1:7890`（Clash/V2Ray），需提前开启。GitHub Actions 环境自动跳过。

## 反检测系统

`collectors/anti_detection.py` — 对抗东方财富反爬：

| 能力 | 说明 |
|------|------|
| UA 轮换 | 7 个 Chrome / Edge UA 随机切换，带 Sec-CH-UA 指纹 |
| 人类延迟 | 高斯分布，每 10 次停 5-15s，每 50 次停 30-60s |
| 请求头伪装 | Accept / Accept-Language / Sec-Fetch 全模拟真实 Chrome |
